04 / FAQ

常见问题

Lemon Loader 支持哪些 Minecraft 版本？

请查看 Releases 中对应版本的说明。目前本页面不对尚未明确发布的版本作兼容承诺。

下载按钮为什么不可用？

目前尚未配置经过验证的正式发行文件。正式发布后会在 GitHub Releases 中提供下载。

遇到问题应该在哪里反馈？

请前往 GitHub 仓库提交 Issue，并附上加载器版本、游戏版本、启动器信息和完整日志。
