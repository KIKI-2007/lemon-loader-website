# Lemon Loader Website

Static landing page and download-center shell for Lemon Loader.

## Deploy on Netlify

- Build command: leave empty
- Publish directory: `.`
- No build step or package installation is required.

## Release checklist

1. Publish a verified Lemon Loader release on GitHub.
2. Add the supported Minecraft/Java versions and installation steps to this page.
3. Replace the disabled download state in `index.html` with the verified release asset URL.
4. Add checksums and release notes before announcing downloads.

The page intentionally does not invent a download URL or compatibility claims.
